# 4.9.2-HF12-HF28

Finale Live-Version auf Grundlage von `4.9.2-HF12-HF27` plus der in TEST21 getesteten wechselseitigen Verbindung zwischen Kicktipp Live Action und Cocos Orakel.

## Inhalt

- In der Kicktipp-Integration führt „Frage Coco“ direkt zu Cocos Orakel.
- In Cocos Orakel führt „Kicktipp Live Action“ direkt zur eingebetteten Kicktipp-Tippübersicht zurück.
- Der bestehende direkte Kicktipp-Zugang bleibt erhalten.

## Installation

1. UPDATE-Paket in das Live-Repository `OldSmugglersClub/the-old-smugglers-club` auf Branch `main` übernehmen.
2. Vorhandene Dateien ersetzen und die drei neuen Versionsdokumente hinzufügen.
3. Keine Dateien löschen.
4. Website anschließend hart neu laden.
5. Beide Wechselrichtungen auf Desktop und Mobil kurz kontrollieren.

`LiveAdmin` wird nicht verändert.

Vorgänger Live: `4.9.2-HF12-HF27`.
