# 4.9.2-HF12-HF29

Finale Live-Version auf Grundlage von `4.9.2-HF12-HF28` plus der in TEST22 und TEST22-HF1 getesteten mobilen und inhaltlichen Bereinigung der Kicktipp-Integrationsseite.

## Inhalt

- Drei Kopfaktionen stehen auf Smartphones in einer Zeile.
- Die Darstellung ist auch für 320 CSS-Pixel angepasst.
- Nicht benötigte technische und erklärende Texte wurden entfernt.
- Fehler-Fallback und sämtliche bestätigten Kicktipp-Funktionen bleiben erhalten.

## Installation

1. UPDATE-Paket in das Live-Repository `OldSmugglersClub/the-old-smugglers-club` auf Branch `main` übernehmen.
2. `kicktipp.html` und `VERSION.txt` ersetzen.
3. Die drei neuen HF29-Dokumente hinzufügen.
4. Keine Dateien löschen.
5. Website anschließend hart neu laden.
6. Smartphone- und Desktop-Darstellung sowie die drei Kopfaktionen kurz kontrollieren.

`LiveAdmin` wird nicht verändert.

Vorgänger Live: `4.9.2-HF12-HF28`.
