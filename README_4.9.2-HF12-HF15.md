# README – Bundesliga-Spieltagsbezeichnung

## Prüfen
1. Hoher Schmugglerrat: „Bundesliga 1. Spieltag“.
2. Counter: „Bundesliga 1. Spieltag“.
3. Spieltagskachel: gleiche dynamische Bezeichnung.
4. Bei Folgespieltagen automatisch „Bundesliga 2. Spieltag“, „Bundesliga 3. Spieltag“ usw.
5. Desktop und Mobile: kein Abschneiden/Überlauf.
6. Smuggleraufträge und andere Wettbewerbe unverändert.

Keine Änderung an Grid, Kachelgrößen oder Grundlayout.
