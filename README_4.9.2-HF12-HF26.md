# 4.9.2-HF12-HF26

Finale Live-Version auf Grundlage von HF25 plus der freigegebenen TEST16-Coco-Integration.

## Inhalt
Coco wird auf der Startseite im Bereich „Spieltags-Logbuch“ dekorativ eingeblendet und schaut von rechts oben in die bestehende Komponente hinein.

Die Änderung verwendet die vorhandene Logbuch-Komponente. Grid, Kachelgrößen, Navigation und Datenlogik bleiben unverändert.

## Installation
UPDATE-Paket in das Live-Projekt übernehmen und vorhandene Dateien ersetzen.

Nach Veröffentlichung die Startseite einmal mit Strg+F5 neu laden, damit CSS und Coco-Grafik sicher nicht aus dem Browser-Cache kommen.
