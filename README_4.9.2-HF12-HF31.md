# 4.9.2-HF12-HF31

Finale Live-Version auf Grundlage von `4.9.2-HF12-HF30` mit der in TEST24 bestätigten automatischen Aktualisierung der Spieltags-Kachel.

## Inhalt

- Die Spieltags-Kachel wechselt beim Beginn des bisher fokussierten Events ohne F5 auf das nächste Event.
- Überschrift, nächstes Spiel, Eventanzahl und Eventliste werden gemeinsam aktualisiert.
- Beim Wiederöffnen eines pausierten Browser-Tabs wird der aktuelle Eventzustand abgeglichen.
- Es erfolgt kein sekündliches Nachladen der Projektdaten.

## Installation

1. UPDATE-Paket in das Live-Repository `OldSmugglersClub/the-old-smugglers-club`, Branch `main`, übernehmen.
2. `index.html` und `VERSION.txt` ersetzen.
3. Die drei neuen HF31-Dokumente hinzufügen.
4. Keine Dateien löschen.
5. Website anschließend hart neu laden.
6. Desktop- und Mobilansicht sowie den nächsten Eventwechsel kontrollieren.

`LiveAdmin` und sämtliche Admin-Dateien werden nicht verändert.

Vorgänger Live: `4.9.2-HF12-HF30`.
