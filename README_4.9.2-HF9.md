# TOSMC Website 4.9.2-HF9

Produktions-Hotfix auf Basis von Website 4.9.2-HF8.

Die Wettbewerbs-Auswahl in der mittleren Highscore-Kachel ist jetzt auf Desktop bereits sichtbar, sobald mindestens ein Wettbewerb eine gefüllte `overall`-Gesamtwertung besitzt. Bei aktuell nur einem verfügbaren Wettbewerb zeigt die Auswahl folgerichtig nur diesen einen Eintrag. Sobald weitere Wettbewerbe Daten erhalten, werden sie automatisch ergänzt.

Die bereits funktionierende mobile Darstellung wurde nicht verändert. Ebenso unverändert bleiben Kicktipp-Ranglogik, Wertungsdaten, Grid, Kachelgrößen und Grundlayout.
