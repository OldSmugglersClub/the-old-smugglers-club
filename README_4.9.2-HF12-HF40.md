# Live-Website HF40 – Website-Mitteilung

Die Mitteilung erscheint regulär vom 25.09.2026 00:00 Uhr bis 28.09.2026 06:00 Uhr in Europe/Berlin.

Vor dem Zeitraum kann sie auf der Startseite mit `?hinweis-vorschau=1` kontrolliert werden. Der Vorschauhinweis ist dabei ausdrücklich sichtbar.

Für spätere Mitteilungen erzeugt LiveAdmin HF11 ein UPLOAD-Paket mit ausschließlich `website-mitteilung.json`.
